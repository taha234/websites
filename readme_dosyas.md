# 🌐 Web Projeleri (Eğitim ve Sunum)

Bu depo, web geliştirme eğitimleri kapsamında hazırlanan ve sunumu gerçekleştirilen örnek web projelerini içermektedir. 

## 📝 Proje Hakkında

Bu projenin temel amacı, web geliştirme teknolojilerini (HTML, CSS, JavaScript vb.) kullanarak teorik bilgileri pratiğe dökmektir. Depo içerisinde yer alan projeler, bir eğitim sürecinin parçası olarak geliştirilmiş ve başarılı bir şekilde sunulmuştur.

## 🛠️ Kullanılan Teknolojiler

Projelerin geliştirilmesi sırasında aşağıdaki teknolojiler kullanılmıştır:

* **HTML5:** Sayfa iskeleti ve anlamsal yapı
* **CSS3:** Tasarım, konumlandırma ve duyarlı (responsive) görünüm
* **JavaScript (ES6+):** Sayfa içi etkileşimler ve dinamik özellikler
* **[Varsa diğer araçlar, örn: Bootstrap, Tailwind, React vs.]**

## 💻 Kurulum ve Kullanım

Projeleri yerel makinenizde çalıştırmak için herhangi bir sunucu kurulumuna veya derleme işlemine gerek yoktur (eğer saf HTML/CSS/JS kullanıldıysa). 

1. Bu depoyu yerel bilgisayarınıza klonlayın:
   ```bash
   git clone https://github.com/taha234/websites.git
   ```
2. İncelemek istediğiniz projenin klasörüne gidin.
3. İlgili klasörün içindeki `index.html` dosyasını favori web tarayıcınızda (Chrome, Firefox, Safari vb.) açın.
   * *İpucu: Eğer VS Code kullanıyorsanız, "Live Server" eklentisi ile anlık olarak görüntüleyebilirsiniz.*
